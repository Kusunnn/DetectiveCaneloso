# DetectiveCaneloso
Detective Caneloso es un videojuego 2.5D de misterio y deducción dirigido a jóvenes y adultos, que ejercite el pensamiento crítico y la atención al detalle mediante una experiencia narrativa de investigación, diferenciándose de los juegos de acción sin trama y juegos de del mismo género que son monótonos o que cuentan con el mismo final.

## HU-10 · Cuaderno de pistas

- **Pausa → Pistas → Pedir una pista** ofrece orientación para el paso actual, sin temporizador ni atajo H.
- Cada orientación solicitada queda en el cuaderno para releerla. Repetir la del mismo paso no duplica entradas ni aumenta el contador.
- El cuaderno se guarda con la partida y se conserva al cambiar entre Campamento, Lago y estación.
- **Opciones → Pantalla → Ayudas de investigación** permite desactivar las solicitudes nuevas y conservar la lectura del historial; es independiente de las ayudas visuales del tutorial.
- Las partidas anteriores recuperan las orientaciones cuyos identificadores se conocen. La pantalla de cierre del Caso 0 incluye las ayudas utilizadas, sin penalizar la calificación.

Comportamiento y pruebas: [HU-10 · Cuaderno de pistas](docs/HU-10_Cuaderno_de_pistas.md).
